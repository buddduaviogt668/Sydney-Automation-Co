Common Dynalite
Failure Symptoms

💡

Zones Stuck On / Off

Entire zones unresponsive or permanently lit. Often a failed DDMC dimmer controller or DyNet network fault.

⛔

Presets Not Triggering

Scene or preset buttons do nothing, or wrong scenes trigger. Usually programming corruption or a failed input device.

⍋

Keypads Dead

DTP panels not responding. Could be a dead keypad, failed power supply, or DyNet bus fault.

🔌

Flickering Lights

Random or consistent flickering across zones. Common sign of a failing DDBC or DBC dimmer module.

🔴

Post Power Outage

Dynalite failed after a blackout or power event. Power supply or programming data may have been affected.

🏠

After Renovation Work

Dynalite stopped working after building works, adding lighting, or wiring changes by another electrician.

FAQs

Dynalite Not Working —
Common Questions

Why is my Dynalite system not working? +
The most common causes of Dynalite system failure: a failed DDMC or DDBC dimmer controller, a DBC power supply fault, DyNet network communication breakdown, a failed keypad or input module, or preset and scene programming corruption. An accredited Dynalite technician can diagnose the fault, typically within the first hour on-site.
Can Dynalite be repaired without replacing the whole system? +
Yes. Dynalite is modular. In nearly all cases, only the failed module needs replacing. Full system replacement is rarely needed. We identify the failed unit and replace only what's necessary.
We don't have the original Dynalite project file — can you still fix it? +
Yes. For hardware failures, the project file is not required. For programming faults, we can retrieve data from the network or rebuild the relevant configuration. Not having the project file does not prevent us from repairing the system.
Can a regular electrician fix a Dynalite fault? +
Not safely. Dynalite requires specific DyNet network knowledge and Dynalite-accredited software tools. A general electrician may cause further damage or programming corruption. Always use an accredited Dynalite specialist for fault finding and repair.
