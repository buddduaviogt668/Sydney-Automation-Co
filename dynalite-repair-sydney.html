FAQs

Dynalite Repair Questions Answered

Can you repair Dynalite systems in commercial buildings? +
Yes. We specialise in Dynalite repair across commercial offices, hotels, restaurants, retail spaces and strata buildings across Sydney. Dynalite is predominantly a commercial platform and we have extensive experience with all DyNet network configurations and Dynalite product families.
How long does a Dynalite repair take? +
Most Dynalite faults are diagnosed within 1-2 hours on-site. Simple module or power supply failures are typically repaired in the same visit. Complex network faults or programming issues may require additional time. We provide an upfront estimate before work begins so there are no surprises.
Do you need the original Dynalite project file to do repairs? +
Not always. For hardware faults like module and power supply failures, we can repair without the project file. For programming and configuration issues, the project file speeds up the process significantly. If you don't have it, we can re-upload from the network or rebuild the relevant sections.
What Dynalite faults do you repair most often? +
The most common Dynalite faults we repair: DDMC and DDBC dimmer controller failures, DBC power supply faults, keypad and input module failures, DyNet network communication errors, preset and scene programming corruption, and relay pack failures. We have seen all of them, most more than once.
Can you repair Dynalite systems that are out of warranty or discontinued? +
Yes. Older Dynalite hardware is still repairable and replaceable in most cases. We stock and source legacy Dynalite modules and can advise on upgrade paths where units are no longer available. Many buildings are still running Dynalite hardware that is 15+ years old and fully serviceable.
