FAQs

Dynalite Repair Questions Answered

Can you repair Dynalite systems in commercial buildings? +
Yes. We specialise in Signify Dynalite repair across commercial offices, hotels, restaurants, retail spaces and strata buildings across Sydney. Dynalite is predominantly a commercial platform and we have extensive experience with all DyNet network configurations and Dynalite product families.
How long does a Dynalite repair take? +
Most Dynalite faults are diagnosed within 1-2 hours on-site. Simple module or power supply failures are typically repaired in the same visit. Complex network faults or programming issues may require additional time. We provide an upfront estimate before work begins so there are no surprises.
Do you need the original Dynalite project file to do repairs? +
Not always. For hardware faults like module and power supply failures, we can repair without the project file. For programming and configuration issues, the project file speeds up the process significantly. If you don't have it, we can re-upload from the network or rebuild the relevant sections.
What Dynalite faults do you repair most often? +
The most common Dynalite faults we repair: DDMC and DDBC dimmer controller failures, DBC power supply faults, keypad and input module failures, DyNet network communication errors, preset and scene programming corruption, and relay pack failures. We have seen all of them, most more than once.
Can you repair Dynalite systems that are out of warranty or discontinued? +
Yes. Older Dynalite hardware is still repairable and replaceable in most cases. We stock and source legacy Dynalite modules and can advise on upgrade paths where units are no longer available. Many buildings are still running Dynalite hardware that is extensive old and fully serviceable.

"My Dynalite lights aren't responding at all in Lilyfield — is it the programming or a hardware fault?"

This is the most common call we get from Lilyfield. Nine times out of ten, it's one of three things: a corrupted group address in the Dynalite network, a failed relay module, or a communication dropout on the bus cable. When we arrive, the first thing we do is plug in the Dynalite toolkit and read the live network — within 10–15 minutes we can usually tell you exactly which unit is at fault and whether it can be fixed on the spot or needs a part ordered. We carry the most common Dynalite modules in the van, so most Lilyfield jobs are resolved same-day.

"How long does a Dynalite repair or reprogramming visit in Lilyfield actually take?"

For a straightforward reprogramming job — say, scenes not working properly or a new switch that needs to be commissioned — plan for 2–3 hours. Fault-finding jobs, especially in older Lilyfield buildings where the dynalite cabling hasn't been touched in 10+ years, can run 3–5 hours if there's physical bus damage involved. We'll always give you a clear estimate before we start and call you if we find something unexpected mid-job. No surprises.

"Can you reprogram my Dynalite system without replacing any hardware in Lilyfield?"

Absolutely — and this is actually the most satisfying part of the job. We've had Lilyfield clients who were quoted full system replacements by other tradespeople, only to find out the entire issue was a scene that had been accidentally overwritten or a unit ID conflict that takes 20 minutes to fix in software. George has been programming Dynalite systems since the Clipsal national support days, so he knows every quirk of the platform. If it can be fixed in software, we'll fix it in software — no unnecessary hardware costs.

We prioritise situations where you've lost control of essential lighting — security lights, common area lights in strata buildings, or systems that have simply gone dark.
