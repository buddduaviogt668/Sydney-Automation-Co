Legacy support
Review first

A missing installer file does not automatically mean the system must be removed. The available system, network and site access determine what can be recovered.

Remote delivery is confirmed after a scope and access review. Physical electrical work remains with the qualified site team.
Why this matters

Protect the investment
already in the walls

Legacy support starts with evidence: what is installed, what still responds, what files exist and who can safely access the network. Remote review may be possible when the system is reachable.

What the site team needs

  • Available project files
  • system photographs
  • network-interface access where possible
  • fault history and a local technician for physical checks.
Defined scope

Built for real projects

Project-file review

Assess any Toolkit files, backups, screenshots or previous documentation available.

Configuration reconstruction

Where technically possible, compare the live system with the required functions and rebuild a workable project structure.

Future support record

Document the recovered system so future changes do not depend on one missing installer or undocumented setup.
