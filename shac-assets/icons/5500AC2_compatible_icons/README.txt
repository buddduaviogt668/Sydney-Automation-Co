SHAC Studio — 5500AC2-compatible icon exports

Use the PNG files in transparent_png first. They are rasterized from the approved gold/brass SVG family and do not depend on SVG rendering, fonts, CSS, gradients, masks, or filters.

If the 5500AC2 image object does not preserve alpha transparency, use the matching PNG in display_png. These have a dark #100D0B background behind the same brass artwork and are intended for the dark SHAC display backgrounds.

The navigation labels are exactly HOME, BACK, and NEXT. The wall_light_sconce_gold file is the simplified wall-mounted light icon.
