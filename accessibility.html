Accessibility

Accessibility Statement

Sydney Automation Co. is committed to ensuring digital accessibility for people of all abilities. We continually improve the user experience for everyone and apply the relevant accessibility standards.

Our Commitment

We strive to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 at the AA level. These guidelines explain how to make web content more accessible for people with disabilities and more user-friendly for everyone.

Measures We Take

  • Semantic HTML structure with proper heading hierarchy
  • Descriptive alt text for all meaningful images
  • Sufficient colour contrast ratios across all text elements
  • Keyboard navigable interface with visible focus indicators
  • ARIA labels on interactive elements where appropriate
  • Responsive design that scales across all device sizes
  • Clear, readable typography using the Barlow font family

Known Limitations

While we strive for full WCAG 2.1 AA compliance, some content may not yet fully meet all criteria. We are actively working to address these areas, including:

  • Some older service pages may have decorative images without alt text
  • PDF documents linked from this site may not be fully accessible

Feedback

We welcome your feedback on the accessibility of the Sydney Automation Co. website. If you encounter any accessibility barriers or have suggestions for improvement, please contact us:

  • Phone: 0422 469 739
  • Email: service@sydneyautomationco.com.au

Standards Applied

This website aims to conform to:

  • Web Content Accessibility Guidelines (WCAG) 2.1 Level AA
  • Disability Discrimination Act 1992 (Cth) — Australia
  • Web Accessibility National Transition Strategy (NTS)
